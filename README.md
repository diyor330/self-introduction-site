
# 自己紹介サイト制作

## 1. プロジェクト概要

HTML、CSS、JavaScriptを使用して、自分のプロフィールや学習経験、スキルなどを紹介するWebサイトを制作しました。

見やすさと使いやすさを意識し、ページのレイアウトやデザインを工夫しました。

## 2. 使用技術

- HTML
- CSS
- JavaScript

## 3. 開発内容

個人開発として、サイトの構成やデザインからプログラミングまで、一人で担当しました。

主に以下の作業を行いました。

- HTMLを使用したページの作成
- CSSによるレイアウトとデザインの調整
- JavaScriptによる画面の動きの実装
- 表示や動作の確認、修正

## 4. 開発目的

これまで学んだHTML、CSS、JavaScriptの知識を活かし、実際にWebサイトを制作することで、Web開発の基礎を身につけることを目的としました。

## 5. 開発形態

個人開発（学校在学中に制作）

## 6. 備考

本サイトは学校在学中に制作したものです。

まだ不具合や修正が必要な部分があるかもしれません。もしバグや気になる点などがありましたら、ご連絡いただけると幸いです。

また、本サイトだけでなく、ポートフォリオとスキルシートもあわせてご覧いただけますと幸いです。
